# Satspot - [LNbits](https://lnbits.com) extension

Money pool games where players pay to join and one random winner takes the pot. Create jackpots that grow as more people participate.

## How it works

Create a satspot with an entry fee. Players pay to join the pool. When the game closes, a random participant is selected as the winner and receives all collected funds minus an optional house fee.

## Features

- Configurable entry amounts
- Automatic random winner selection
- Optional house fee (haircut)
- Multiple concurrent games

## Usage

1. Enable the extension in LNbits
2. Create a satspot with entry fee and duration
3. Share the game link
4. Players join by paying the entry fee
5. Winner is selected automatically when game ends
